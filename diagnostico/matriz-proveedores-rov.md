## 2. Lectura rapida para el proyecto

### Si el objetivo es ArduSub / ArduPilot
La ruta mas coherente sigue siendo:
1. Blue Robotics como referencia de ecosistema.
2. Distribuidor regional Blue Robotics para logistica, idealmente Adentu SUB en Chile por idioma y cercania.
3. Water Linked solo si se necesita posicionamiento submarino real.
4. Impact Subsea/Keller si se buscan sensores mas industriales que Bar30.

### Si el objetivo es recuperar el FIFISH V6 Expert
La ruta sigue siendo QYSEA/RMA. Los proveedores de ROVs completos no resuelven la reparacion ni la conversion; compiten con el equipo ya existente.

### Si el objetivo es comprar un ROV completo en vez de convertir
Comparar BlueROV2/BlueBoat contra Blueye, Chasing, Deep Trekker y QYSEA segun presupuesto, soporte y apertura. Para este proyecto, BlueROV2 es el mas alineado con ArduSub.

## 4. Que verificar antes de contactar proveedores

- Si venden a Argentina directamente o solo via distribuidor.
- Incoterm: EXW, FOB, DAP, DDP.
- Si la bateria Li-ion puede enviarse por aire o debe excluirse.
- Codigo HS y documentacion para importacion temporal o definitiva.
- Garantia aplicable fuera del pais de compra.
- Stock real de T200/Basic ESC/Navigator/Bar30/Fathom-X.
- Si ofrecen penetradores, conectores y O-rings compatibles con el casco elegido.
- Si pueden integrar o ensamblar el ROV como servicio.
- Tiempo de entrega total, no solo tiempo de fabricacion.
- Soporte tecnico en espanol y zona horaria.

---

## 5. Recomendacion practica

Para el proyecto ROV Analisis, el orden de contacto sugerido es:

1. Reparacion/RMA del V6 con QYSEA o centro autorizado, si todavia se quiere recuperar el equipo original.
2. Adentu SUB Chile para consultar disponibilidad regional de componentes Blue Robotics y soporte en espanol.
3. Blue Robotics directo solo si el distribuidor regional no resuelve stock, precio o documentacion.
4. Water Linked unicamente si el proyecto evoluciona a position hold submarino serio.
5. Resto de proveedores como comparacion de sensores o ROVs completos, no como ruta principal.
